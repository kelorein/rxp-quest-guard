# Security policy

Report a suspected vulnerability using [GitHub private vulnerability reporting](https://github.com/kelorein/rxp-quest-guard/security/advisories/new). If the reporting form is unavailable, open an issue asking for a private reporting channel and keep the vulnerability details out of that issue.

Include the affected version, a description of the impact, and the smallest reproduction you can share. Use synthetic data and redact API keys, account and character details, local paths, and proprietary guide content. If you exposed an API key, revoke it with the provider before contacting maintainers.

Give maintainers time to investigate and coordinate disclosure. Use regular GitHub issues for compatibility and other non-security bugs.
